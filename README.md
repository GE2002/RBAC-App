# RBAC Mini-App

My Python program uses two usernames to simulate a login.
Each account has a role that controls its access.

-ginna_admin can only access the admin dashboard.

-ginna_user can only access the user dashboard.

-Unknown usernames get a login failed message.

To run it, open RBAC_App.py in VS Code and click Run Python File.
Change the username to test each account.

This shows confidentiality because each account can only access
the dashboard allowed by its role. This is a login simulation,
so it does not use passwords.
